## 🎧 Sobre o projeto

O **Wave Music** é um projeto front-end desenvolvido com o objetivo de criar uma landing page moderna e visualmente atrativa para uma plataforma de música.

A interface foi construída utilizando **HTML e CSS**, com elementos visuais, estilização personalizada e animações para proporcionar uma experiência mais dinâmica ao usuário.

O projeto coloca em prática conceitos de desenvolvimento front-end, organização de layouts e criação de interfaces para aplicações web.

---

## ✨ Funcionalidades

- 🎵 Interface inspirada em plataformas de música
- 🎨 Layout moderno e personalizado
- ✨ Animações em CSS
- 🖥️ Organização visual dos elementos
- 🎧 Apresentação de conteúdo relacionado à música
- 🌐 Interface desenvolvida para web
